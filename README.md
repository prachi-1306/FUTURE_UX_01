# Glow-Salon-Website-Redesign-
## ✨ Project Overview
##### • This project focuses on redesigning a salon business website with a modern and conversion-focused user interface.
##### • This website was created to improve customer interation, simplify appointment booking, and provide a seamless browsing experience across devices.
##### • The redesign includes visually engaging Home, Services and Contact pages with structured layouts, clear call-to-action sections, service highlights and trust-building elements.
##### • Special attention was given to responsive design, clean navigation, and user-friendly booking flow to enhance both usability and customer.
## 🎯 Objective
##### • To redesign the salon website with a modern and elegant UI.
##### • To improve user experience through clean navigation and structured layouts.
##### • To showcase salon services in a visually appealing manner.
##### • To make appointment booking simple and accessible.
##### • To create a responsive and professional salon web interface.
